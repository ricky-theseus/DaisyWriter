# 短中篇 · 双路盲审

## 入口

主 agent 传入参数：正文路径、项目路径。

审前 Read 项目配置：

```bash
Read {项目路径}/工艺约束.md
Read {项目路径}/章节规划.md
```

`工艺约束.md` 标注了平台、对话符号、字数门禁等格式规则。
**不读 config.json，项目里没有这个文件。**

## 第一路：硬规则审查

Read `工艺约束.md` 中的格式约束，逐条对照正文检查：

| 检查项 | 阻断条件 |
|--------|---------|
| 场景字数 | 任一场景 <400 或 >800 |
| 段落句数 | 任一段落 >2 句号 |
| 对话符号 | 与工艺约束不一致 |
| 禁用词 | 出现即阻断 |
| 角括号 | 出现即阻断 |
| 章节号 | 正文出现"第N章" |
| 标记文字 | 出现 [试读 等标记 |
| 导语格式 | 无导语或导语>6句 |

可用 check.py 辅助机械检查：

```bash
python <skill_dir>/../shortstory-write/check.py {正文.md路径}
```

有阻断 → 只输出硬规则结果，不进入软规则。

## 第二路：软规则审查

扫描 `短篇/参考书/{类型}/`，读 2-3 篇参考文前 1000-2000 字。
如果目录不存在，跳过软审查。

| 维度 | /10 | 说明 |
|------|:---:|------|
| 语感一致性 | /10 | 和参考文的语气/节奏/用词倾向是否接近 |
| 自然度 | /10 | 有没有机器拆段式短句堆叠、生硬句式 |
| 段落节奏 | /10 | 是否该长则长该短则短，不机械 |
| 整体阅读感 | /10 | "读小说的感觉"到了没有 |

任一维度 <6 → 阻断，给出修改建议。

## 存盘

审查报告写入 `{项目路径}/审查报告/` 目录。

```bash
# 创建目录（如不存在）
New-Item -ItemType Directory -Path {项目路径}/审查报告 -Force

# 单次审查写入
Write {项目路径}/审查报告/第{章号}章_审查报告.json
```

文件名格式：`第{章号}章_审查报告.json`。全篇终审用 `终审_审查报告.json`。

## 输出格式

```json
{
  "chapter": 1,
  "hard": {"passed": true/false, "issues": []},
  "soft": {
    "passed": true/false,
    "scores": {"语感一致性": 0, "自然度": 0, "段落节奏": 0, "整体阅读感": 0},
    "suggestions": []
  },
  "overall": "pass / revise / blocked"
}
```

# 短篇扫榜

> 专注盐选/短篇平台。短篇市场变化快，题材信号有效期短，扫榜报告必须标注样本日期。

## 触发方式

用户说了以下任何一句，**直接启动扫榜流程**，不需要问：

| 用户说 | 对应动作 |
|--------|---------|
| "看看最近什么题材火" / "短篇有什么流行" | 问平台方向 → 采集 → 分析 → 出报告 |
| "扫一下知乎盐言" / "看看盐言在流行什么" | Phase 1 确认类型方向 → 目标采集 → 出报告 |
| "最近言情有什么趋势" / "悬疑短篇好写吗" | 携带类型方向提问 → 直接进入对应平台扫榜 |
| "/shortstory-scan 盐言" | 直接按平台名执行 |

扫榜完成后输出：
1. `短篇/扫榜/{平台}_{日期}.md` — 扫榜报告
2. 口述市场发现和选题建议（不自动写候选）

## 流程

### Phase 1：确认平台和方向

问用户：**「你想看哪个平台？（知乎盐言/番茄短篇/七猫短篇/黑岩/点众）有没有聚焦的类型方向？」**

如果用户已给出，直接下一阶段。

### Phase 2：采集

| 平台 | 采集方式 | 目标页面 |
|------|---------|---------|
| 知乎盐言 | Playwright 浏览器 + 列表页遍历 + 逐个点开详情 | 盐选热门榜单、推荐列表 |
| 番茄短篇 | Playwright 浏览器遍历榜单 | 男频/女频阅读榜、新书榜 |
| 七猫短篇 | Playwright 浏览器遍历 | 排行榜总入口 |
| 黑岩 | Playwright 浏览器（可能需要登录） | 书库列表、短篇板块 |
| 点众 | Playwright 浏览器 | 男频/女频短篇列表 |

**采集字段（每篇）：**

```
标题 | 作者 | 题材标签 | 字数 | 点赞/热度 | 开头200字 | 情绪标签
```

**采集规模：** 每个榜单至少采集 Top 20-30 篇。如果页面分页，爬至少 2 页。

### Phase 3：分析

从采集数据中提炼：

| 维度 | 检查点 |
|------|--------|
| 题材分布 | 哪些题材占比最高？新题材信号？ |
| 情绪趋势 | 虐/甜/爽/悬疑的比例？情绪拉满型 vs 轻松型？ |
| 开头模式 | Top 10 的开头手法有什么共性？ |
| 标题模式 | 高频关键词、句式结构 |
| 人设模型 | 当前主流的人设组合（姐弟/追妻/白月光等） |
| 篇幅分布 | 主流是 1-2 章还是 3-5 章？平均字数？ |
| 作者结构 | 老作者霸榜 vs 新人有机会？ |

### Phase 4：输出扫榜报告

输出到 `短篇/扫榜/`，文件名 `{平台}_{日期}.md`：

```markdown
# 短篇扫榜报告：{平台}

**扫榜时间：** {日期}
**样本量：** {采集篇数}
**类型聚焦：** {如有指定}

## 市场概况

{核心发现，200-300字}

## 题材热度排行

| 排名 | 题材 | 上榜数量 | 趋势 |
|------|------|---------|------|
| 1 | {题材} | {N}篇 | 🔥/⚡/⬇️ |

## 情绪类型分布

| 情绪类型 | 占比 | 说明 |
|---------|:----:|------|
| 虐恋 | {N}% | {观察} |

## 开头模式 Top 5

1. **{模式名}**（{N}篇使用）
   - 公式：{抽象模板}
   - 示例：「{代表作开头句}」

## 标题高频词

`{词1}` `{词2}` `{词3}` ...

## 人设模型趋势

{当前主流人设组合 + 变化方向}

## 风口预警

- 🔥 正在爆发：{题材}
- ⚡ 即将起风：{题材}
- ⚠️ 即将饱和：{题材}

## 选题建议（口头）

{基于以上数据的 2-3 条选题方向，直接口述}
```

### Phase 5（可选）：写选题决策文件

如果用户想保存选题建议，输出到 `短篇/候选/{类型}/{方向名}.md`：

```markdown
# 选题：{方向名}

来源扫榜：{平台}，{日期}

## 能爆的理由
## 差异化定位
## 可行性
## 风险
## 验证动作
```

## 平台特性速查

| 平台 | 调性 | 核心指标 | 主力读者 | 适合类型 |
|------|------|----------|----------|----------|
| 知乎盐言 | 精品短篇，情绪深度 | 付费转化率 | 20-35 都市男女 | 虐恋、反转、悬疑、家庭 |
| 番茄短篇 | 下沉市场，脑洞优先 | 在读数/完读率 | 大众读者 | 强爽感、快节奏 |
| 七猫短篇 | 免费阅读，快节奏 | 热度 | 大众读者 | 快节奏爽文 |
| 黑岩短篇 | 极端情绪，节奏极快 | 完读率 | 混合 | 虐恋、复仇、反转 |
| 点众短篇 | 精品快节奏 | 完读率/付费 | 混合 | 家庭复仇、假千金 |

## 注意事项

- **短篇热点变化快**：两周前的报告可能已经过时，报告必须标注日期
- **不要依赖记忆中的趋势**：每次扫榜必须重新采集，数据说话
- **不产出选题决策文件**除非用户要求——扫榜报告本身已经够用
- **采集时注意页面反爬**：适当等待，不要高频请求

# 短篇平台扫榜指南

## 知乎盐言

**网址：** https://www.zhihu.com/yanxuan/
或 https://www.zhihu.com/yanxuan/hot（热门榜单）

**扫榜策略：**
- 榜单页采集 Top 20-30 篇
- 点击每篇进入详情页，提取开头 200 字
- 关注：付费转化率（如果有）、标签、评论区情绪

**注意：** 知乎页面常为 SSR/动态加载，用 Playwright 的 browser_navigate + browser_snapshot 获取列表，然后逐个 browser_navigate 进详情页。

**判断标准：**
- 高赞+高评论 = 情绪拉扯力强
- 标题含"我""他/她"人称 + 强烈动词 = 高点击率信号
- 开头 3 句话有冲突/悬念 = 高完读率信号

## 番茄短篇

**网址：** https://fanqienovel.com/（遍历榜单页面）

**榜单类型：** 男频阅读榜、女频阅读榜、新书榜

**扫榜策略：**
- 使用 Playwright 浏览器访问榜单页
- 提取标题、作者、标签、简介
- 注意：番茄页面大量 JS 渲染，需等待加载

## 七猫短篇

**网址：** https://www.qimao.com/（排行榜入口）

**榜单类型：** 大热榜、新书榜

**扫榜策略：**

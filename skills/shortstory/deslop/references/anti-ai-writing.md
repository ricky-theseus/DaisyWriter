# 短篇去AI味完整指南

> 适配自 webnovel-deslop anti-ai-guide + qu-ai-wei + 翔宇8特征。
> 核心概念：AI味的本质是"节奏指纹"——句长方差、词汇可预测性、情感曲线平坦度。

## AI味全景（8维）

| # | 维度 | 核心问题 | 严重度 |
|---|------|---------|:-----:|
| A | 句式节奏 | 句子长度和结构太相似 | ★★★★★ |
| B | 词汇模板 | 空洞套话、禁用词堆砌 | ★★★★★ |
| C | 逻辑规整 | 教科书式起承转合 | ★★★★ |
| D | 语气正经 | 缺少口语和变化 | ★★★★ |
| E | 情感扁平 | 中立客观，没有温度 | ★★★★ |
| F | 修辞公式 | "不仅…而且"反复出现 | ★★★ |
| G | 细节缺失 | 全是形容词没有名词 | ★★★★★ |
| H | 过度完美 | 语法零错误、结构零瑕疵 | ★★★ |

## 平台差异策略

### 知乎盐选（第一人称，女频单POV）

| 维度 | 激进度 | 要点 |
|------|:-----:|------|
| A:节奏 | 激进 | 口语短句为主，长句打碎。朗读检验 |
| B:词汇 | 激进 | "我不禁""我意识到"必须改 |
| C:逻辑 | 激进 | 否定前置、转折句式全砍 |
| D:语气 | 激进 | "因而→所以""此外→还有"。加口语"说真的""我跟你讲" |
| E:情感 | 激进 | 第一人称情绪必须外化+感官 |
| F:修辞 | 中等 | 减少排比，保留部分白描 |
| G:细节 | 激进 | 每段至少一个具体细节 |
| H:瑕疵 | 激进 | 加2-3处口语化瑕疵 |

### 番茄短篇（第一人称推荐，""对话）

| 维度 | 激进度 | 要点 |
|------|:-----:|------|
| A:节奏 | 中等 | 控制段落长度（2-3句/段最佳） |
| B:词汇 | 激进 | 禁用词全检查。番茄特有"宝藏""神器"类保留 |
| C:逻辑 | 中等 | 悬疑类需保留部分逻辑链 |
| D:语气 | 中等 | 番茄接受一定文学性，去过度书面即可 |
| E:情感 | 中等 | 外化核心情绪，保留部分内心独白 |
| F:修辞 | 中等 | 保留悬疑类修辞，砍抒情类 |
| G:细节 | 中等 | 关键场景加细节，过渡段不强制 |
| H:瑕疵 | 轻度 | 适当加口语，不过度 |

### 通用第三人称

| 维度 | 激进度 | 要点 |
|------|:-----:|------|
| A:节奏 | 保守 | 保留文学性节奏，只改明显均质段落 |
| B:词汇 | 激进 | 禁用词全改 |
| C:逻辑 | 保守 | 保留正常叙事逻辑，砍否定前置 |
| D:语气 | 保守 | 保持书面风格，只改"旨在→是为了"级别 |
| E:情感 | 中等 | 外化核心情绪即可 |
| F:修辞 | 保守 | 保留正常修辞，砍连续排比 |
| G:细节 | 中等 | 关键场景加细节 |
| H:瑕疵 | 轻度 | 不加口语瑕疵 |

## AI检测工具检测原理

| 工具 | 原理 | 针对策略 |
|------|------|---------|
| GPTZero | 困惑度+突发性分析 | 句长方差、情感曲线 |
| 朱雀AI检测 | 中文专有模式匹配 | 禁用词、格式化开头、套话密度 |
| 原创检测 | 人工+统计混合 | 词汇多样性、句子可预测性 |

核心对策：增加句长方差（burstiness），降低词汇可预测性，加入情感波动。

## 常见AI模式速查

### 开头AI腔（短篇高频）

| AI开头 | 人味开头 |
|--------|---------|
| "那是一个普通的下午" | "我又迟到了。" |
| "我从未想过…直到…" | 直接从事件切入 |
| "人生中总有一些时刻" | "那是我第一次见到死人。" |
| "这个故事要从…说起" | 直接讲故事 |

### 对话AI腔

| AI味对话 | 人味对话 |
|----------|---------|
| "你还好吗？"他关切地问 | "没事吧你？"他递过来一瓶水。 |
| "我不知道该怎么回答" | "嗯……"我咬了咬下唇。 |
| 每句对话都带标签 | 用动作标签替代50%以上 |
| 解释性对话 | 删，角色不会说清自己的动机 |

### 心理描写AI腔

| AI味 | 人味 |
|------|------|
| "我心里一阵难受" | "眼泪啪嗒掉在手背上。" |
| "我很紧张" | "手心里全是汗。" |
| "我感到很温暖" | "那杯热茶的温度透过杯壁传过来。" |
| "我不禁想到" | （直接写想到的内容） |

### 结尾AI腔

| AI味结尾 | 人味结尾 |
|----------|---------|
| "那一刻，我终于明白…" | 用行动收尾 |
| "原来生活就是这样" | 留白，不总结 |
| "新的篇章刚刚开始" | 直接删 |
| "这一切都让我意识到" | 删，让读者自己得出结论 |

## 常见误判（不动的情况）

以下表达在短篇中是合法的，不要误判为AI味：

- 知乎盐选的"他/她"指代系统（单POV限制）
- 悬疑类的逻辑链条（推理需要连接词）
- 角色个性化方言或口头禅
- 刻意使用的排比修辞（主题需要）
- 引用或书摘

## 8维精修示例

### 原文（AI味重，知乎盐选风格）

> 我不禁感到一阵紧张。这是一个重要的时刻，我知道自己必须做出选择。然而，我犹豫了。那一刻，时间仿佛凝固了。我终于意识到，人生中的每一个决定都可能改变我们的命运。

### 改后（8维逐项）

> 我攥紧了手里的笔。对面那个人还在等。
>
> "快点。"他说。
>
> 手心全是汗。我深吸一口气。
>
> 其实选什么不重要——重要的是得选一个。上还是不上，就这么简单。

### 改动说明

| 原句 | 维度 | 改动 |
|------|------|------|
| "我不禁感到一阵紧张" | B+E | → "攥紧笔""手心全是汗"（情感外化+动作） |
| "这是一个重要的时刻，我知道自己必须做出选择" | C+G | → "对面那个人还在等。'快点。'"（具体场景+对话） |
| "然而，我犹豫了" | B | → 删"然而"（禁用词） |
| "那一刻，时间仿佛凝固了" | A+H | → "我深吸一口气"（拉回现实节奏） |
| "我终于意识到…改变命运" | C+F+G | → "其实选什么不重要"（口语化+去升华） |

# 短篇去AI味 · shortstory-deslop

适配自 `webnovel-deslop`（7-Gate）+ `qu-ai-wei`（51模式）+ 翔宇8特征。

**核心信念：AI 味的主要问题并非语法错误，而是过度圆滑、工整、解释充分。改写目标是保留剧情功能，同时增加口语、停顿、跳跃和具体动作。**

## 核心原则

### 原则 1：改味优先，别当改错
AI味属于风格问题：过于书面化、对仗工整、面面俱到。目标是让文字回归具体、自然、可读。

### 原则 2：改最少，效果最大
能改一个词就不改一句，能删一句就不重写一段。没有问题的句子尽量保留原句。删除比例上限：轻度 ≤15%，中度 ≤25%，重度 ≤35%。

### 原则 3：保留创作意图
只改"怎么说"，不改"说什么"。剧情、人设、情节走向一概不动。不能删除伏笔、钩子、角色特征、关键信息或必要转折。

### 原则 4：人称感知
- **第一人称**：去AI激进（口语化优先，砍煽情），多用口语短句打断节奏
- **第三人称**：去AI中等偏保守（保留文学性，砍连接词和解释腔）

## 短篇 vs 长篇差异要点

| 差异项 | 长篇网文 | 短篇 |
|--------|---------|------|
| 人称 | 第三人称为主 | 第一人称占很大比例 |
| 字数 | 10万+字 | 8K-60K字 |
| 粒度 | 章节 | 场景（200-800字） |
| 统计信号 | 强（多章平均） | 弱（场景短，句长方差不可靠） |
| 节奏模式 | 张弛交替 | 紧凑冲刺（短篇需要更快进入冲突） |
| AI高频词 | "他不禁""眼中闪过" | "我不禁""我意识到" |

## 检测流程

### Phase 1：AI味扫描

加载 `references/banned-words.md`，对照禁用词表扫描。

扫描结果标记 8 维问题位置，输出 AI味检测报告：

```
## AI味检测报告（短篇版）

### 整体评估
- AI味等级：{轻度/中度/重度}
- 主要问题：{1-3 个关键词}

### 问题标记
| 位置 | 原文 | 维度 | 问题 |
|------|------|------|------|
| 第X段 | "我不禁感到…" | B:词汇模板 | 第一人称禁用词 |
| 第Y段 | "这不仅仅…更是…" | C:逻辑规整 | 否定前置句式 |
| 第Z段 | "他很紧张" | E:情感外化 | 直接陈述情绪 |
| 第M段 | 段段4-6句、长度均匀 | A:句式节奏 | 整段同节奏 |
| 第P段 | "她不知道的是…" | H:瑕疵注入 | 叙述者跳出角色 |
```

### Phase 2：诊断与分级

| 程度 | 禁用词密度 | 特征 | 处理策略 |
|------|-----------|------|-----------------|
| 轻度 | ≤5/千字 | 少量禁用词，偶有书面腔 | 仅过 A + B + D |
| 中度 | 6-15/千字 | 多处禁用词+句式套路+情绪直述 | 过 A+B+C+D+E+H |
| 重度 | >15/千字 | 全文明显，节奏/对话/情感/解释腔均有问题 | 完整 8 维 + 重点段落重写 |

综合判定规则：取八项指标（禁用词密度、句长方差、非A是B句式、心理词占比、情绪标签密度、平均段落句数、连接词密度、修辞堆叠密度）的最高档位。

### Phase 3：逐维清除

根据人称调整激进度：第一人称最激进（口语化优先），第三人称中等（保留文学性）。

#### 维度 A：句式节奏

- **检测**：连续 5 句字数在 15-25 字范围内 → 节奏均质
- **修改**：拆一句变短（5-8 字），或合并两句变长（30+ 字）
- **第一人称特殊处理**：用口语短句打断节奏
- **朗读检验**：读出声——读起来拗口的地方就是需要改的地方

#### 维度 B：词汇模板

- **检测**：对照 `references/banned-words.md` 逐项检查
- **替换规则**：禁用词 → 具体动作/细节描写
- **第一人称特有**："我不禁" → 直接写动作。"我意识到" → 删或改写发现过程
- **不能**简单换成另一个形容词
- **白名单**：项目根目录下 `.deslop-whitelist` 定义豁免词汇

#### 维度 C：逻辑过度规整

| 句式 | 替代方案 |
|------|----------|
| 否定铺垫后接肯定翻转（"不是…而是…"） | 直接写后项，或改成动作/细节呈现 |
| "不仅仅…更/还…" | 删"不仅仅"，只说重点 |
| "从X到Y"虚假范围 | 只写相关的那一项 |
| 连续排比 | 保留 1-2 个，删掉其余 |

**第一人称特殊**：开头常有"我从未想过…直到…"模式 → 删前段，从"直到"后直接开始。

#### 维度 D：语气一本正经

按人称替换：

| AI 爱用 | 第一人称替换 | 第三人称替换 |
|---------|-------------|-------------|
| 因而 | 所以 | 因此/所以 |
| 旨在 | 就是为了 | 是为了 |
| 回看全貌 | 总之 | 总体来看 |
| 此外 | 还有 | 此外/另外 |
| 值得注意的是 | 说实话 | 值得注意 |
| 至关重要 | 太重要了 | 至关重要（保留） |
| 不允许 | 不行 | 不允许/不能 |

**第一人称语气注入**：加入"说真的""我跟你讲""怎么说呢""你猜怎么着"

#### 维度 E：情感外化

直接陈述情绪 → 用行为展示：
- "我很紧张" → "我的手在抖"
- "她很难过" → "她盯着桌面，半天没说话"
- "他感到温暖" → "他把那杯热水握在手心，没松开"

**短篇特殊**：第一人称情感外化时，加入感官细节（触觉/听觉优先于视觉）
- "我很害怕" → "后颈一阵发凉，我下意识攥紧了衣角"
- "我很难过" → "嗓子像堵了团棉花"

#### 维度 F：修辞去公式

| 模式 | 问题 | 修改 |
|------|------|------|
| "不仅…而且…更重要的是…" | 三段式堆叠 | 简化："A，同时 B"或只说 A |
| "不是X，不是Y，而是Z" | 否定对举滥用 | 直接写 Z |
| "从X到Y，从A到B" | 虚假范围排比 | 砍到一项 |
| 连续顿号并列（"X、Y、Z"） | 过于工整 | 改口语化："X、Y还有Z" |

**阈值**：一篇文章里同一种修辞模式出现超过 2 次 → 至少砍掉 1 次。

#### 维度 G：细节注入

**原则**：每个段落至少有一个具体事实（数字、名称、场景描写）。

| AI 写法 | 人的写法 |
|---------|---------|
| "工作效率提高了很多" | "处理速度从 3 天缩短到 4 小时" |
| "环境很差" | "地上全是脚印，桌上堆着外卖盒" |
| "他很好看" | "他穿一件灰色卫衣，笑起来眼睛弯弯的" |
| "团队很努力" | "连续加了两个星期的班" |
| "很久以前" | "三年前的那个冬天" |
| "某些地区" | "杭州余杭区" |

**不能虚构事实**。原文没有具体数据时用场景描写代替抽象概括。

#### 维度 H：瑕疵注入（短篇特有）

允许以下"不完美"加入：

- **第一人称口语化**："说实话""讲真""我也说不清楚"
- **个别断句**："就这样。没了。"
- **承认不确定**："这个我也说不好，但感觉…"
- **个人化吐槽**："我当时真想找个地缝钻进去"
- **不工整段落**：偶尔一段只有一句话

**阈值**：一篇文章 2-3 处，不滥用。

### Phase 3.5：复扫验证

1. 重新扫描禁用词和 8 维模式
2. 检查是否引入新 AI 味（如过度口语化 = 另一种 AI 腔）
3. 检查字数变化（删除比例不得超上限）
4. 检查关键信息是否被误删

### Phase 4：输出润色报告

```
## 去AI味润色报告

### 字数协议
- 原文字符数：{N0}
- 修订后字符数：{N1}
- 净变化：{N1 - N0}（{百分比}）
- 是否在比例上限内：{是/否}

### 修改统计
- 总修改数：{N} 处
- 禁用词替换（B）：{N} 处
- 句式调整（C）：{N} 处
- 语气替换（D）：{N} 处
- 情感外化（E）：{N} 处
- 修辞去公式（F）：{N} 处
- 细节注入（G）：{N} 处
- 瑕疵注入（H）：{N} 处
- 节奏调整（A）：{N} 处
```

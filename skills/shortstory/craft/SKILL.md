# 短篇写作工艺约束

## 通用硬规则

| 规则 | 说明 |
|------|------|
| 禁用词 | 然而、值得一提、由此可见、事实上、不难看出、综上所述、与此同时、不可否认 |
| 过渡词 | 日子一天天过去、时间过得很快、不知不觉、转眼间、就这样、没过多久（可用，但>3处标记） |

## 加载方式

写章或审查前，先 Read 项目根目录的 `工艺约束.md`，从中获取平台、对话符号、字数门禁、本篇特殊约束。
